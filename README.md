# Bill's Mushroom Grow Project

Documentation for the automated mushroom growing operation.

## Projects

- [XIAO/LoRa CO2 monitoring](https://github.com/billjuv/XIAO-LoRa-CO2-monitoring) - A wireless CO₂, temperature, and humidity monitoring system for mushroom grow operations, using LoRa radio to send sensor data to a central MQTT broker — no WiFi required on the sensor node.
- [EC Fan ESPHome](https://github.com/billjuv/EC_Fan_ESPHome) — ESPHome configuration for EC fans for use with MQTT, Node-RED dashboards, Home Assistant, or Mycodo - powered by the fan.
- [EC PWM Fan Control Boards](https://github.com/billjuv/EC_PWM_FanControlBoards) — Stand-alone PWM fan control boards. These boards were designed for controlling EC fans that use USB-C connectors for PWM speed control. They are modifications of Kyle Gabriel's Mycodo fan control boards for TerraBloom EC fans, adapted to use USB-C connectors instead of audio connectors. 
- [Govee BLE Sniffers with OpenMQTTGateway](https://github.com/billjuv/OMG-ESP32-BLE_govee_sniffer) — ESP32 boards that monitor Govee temperature/humidity sensors via Bluetooth and forward data to MQTT via WiFi.

## Related

- [ESP32-Renogy-LoRa](https://github.com/billjuv/ESP32-Renogy-LoRa)) - A standalone LoRa transmitter that gets power and reads data from a Renogy solar charge controller via RS232 and sends solar data to a central MQTT broker. This project uses an ESP32 DevKit-v1 and an Adafruit RFM95W LoRa transceiver.
- [ESP32-S3_XiAO-Renogy-LoRa](https://github.com/billjuv/ESP32-S3_XiAO-Renogy-LoRa) - A smaller, less expensive version of ESP32-Renogy-LoRa using a SeeedStudio ESP32-S3 XIAO/LoRa Kit and a smaller, easier to wire RS232->TTL board.
